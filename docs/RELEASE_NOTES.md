# DesktopSpaces 0.1.0 preview

First preview of the Windows tray utility: independent folder spaces,
double-click cycling, Alt + 1–9 / Ctrl + Alt + 1–9, native Shell views,
space management, persistent icon layouts, opt-in startup, and desktop path
recovery through a journal and a separate watchdog.

This build is intended for testing. Review README and VALIDATION before use.
Cached save paths, OneDrive-managed desktops, folder context-menu differences
and incomplete validation of continuous drag transfer and Windows 10/multiple
monitors are documented. The x64 zip includes the .NET runtime and notices.
